This is a new troubleshooting method for Windows. But you need to search and fix manually. This approach gives the user more control, called GodMode.

Not sure if it is available on other Windows versions, but I will provide instructions on how to set it up on Windows 11 Home. 


## Step 1:
Create a folder

## Step 2:
Name it:
```
GodMode.{ED7BA470-8E54-465E-825C-99712043E01C}.
```

Done.
